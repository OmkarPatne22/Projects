### 📊 Amazon Prime Users Dashboard

📌 Overview

This dashboard provides an in-depth analysis of Amazon Prime users based on their subscription plans, demographics, device usage, and content preferences. It helps understand user behavior, subscription patterns, and engagement levels for better decision-making.

🔑 Key Insights

Total Users: 2,343

Total Genres: 7 | Total Ratings: 28

Subscription Status: 95.69% Active, 4.31% Expired

Subscription Plans:

Annual: 1,186 users

Monthly: 1,157 users

Age Distribution: Balanced spread across all age groups from 5 to 64 years.

Device Usage:

Smartphones: 804 users (34.31%)

Smart TVs: 799 users (34.1%)

Laptops: 739 users (31.54%)

Tablets: Minimal usage

Most Popular Genres: Drama, Comedy, Horror, Action, Romance, Documentary, Sci-Fi

Membership Duration: Majority at 365 days, highlighting yearly active subscribers.

🛠 Tools & Technologies

Power BI – for dashboard design & visualization

DAX – for calculated measures and KPIs

Data Cleaning & Transformation – Power Query

🎯 Features

Interactive filters by Year, Subscription Plan, and Location

User segmentation based on age, device, and membership duration

Visual representation of genre preferences and subscription activity

Easy comparison between annual vs monthly subscribers

🚀 Purpose

This dashboard helps businesses:

Identify device preferences for targeted platform optimization.

Understand content genre popularity to enhance recommendations.

Monitor subscription trends (active vs expired) for retention strategies.

Analyze demographics to improve customer experience.
