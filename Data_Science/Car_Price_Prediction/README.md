
# 🚗 Car Price Prediction  

[Streamlit App](https://carprice--prediction.streamlit.app/)  

A **Machine Learning Web Application** built using **Streamlit** that predicts the price of a car based on its specifications such as **make, model, year, mileage, fuel type**, and more.  

---

## ✨ Features  
- **Interactive Web Interface** – Enter car details and get instant price predictions.  
- **Machine Learning Model** – Trained using **Linear Regression** for accurate predictions.  
- **Deployed on Streamlit Cloud** – No setup required, runs directly in the browser.  

---

## 🛠 Tech Stack  
- **Programming Language:** Python  
- **Libraries:** pandas, numpy, scikit-learn, streamlit, pickle  
- **Model:** Linear Regression  
- **Dataset:** [Kaggle Car Price Dataset](https://www.kaggle.com/)  
- **Deployment:** Streamlit Cloud

## ⚙️ How to Run Locally  
1. Clone the repository:

   git clone https://github.com/OmkarPatne22/Projects/tree/main/Data_Science/Car_Price_Prediction.git
   cd car-price-prediction

2. Install dependencies:
   
   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py
